# Superstore Analytics Dashboard

This project demonstrates data analysis skills using **Excel** with **Power Query**, **PivotTables**, and **KPIs**. It includes:
- Data cleaning and transformation using Power Query
- PivotTable analysis for **sales**, **region performance**, and **customer segmentation**
- An interactive **dashboard** with slicers and charts for visual representation
- Advanced **Excel functions** used for daily business tasks like **SUMIF**, **VLOOKUP**, and **INDEX-MATCH**.

## How to Use:
- Open the **Superstore_Analytics_Dashboard.xlsx** file to view the dashboard and explore the analysis.
